# 围绕任务四的学习清单

依次学习并完成小练习，不需要先学完全部 ROS 或从头训练检测模型。

1. Python 与终端：运行脚本、理解报错、文件路径、列表和字典、读写 YAML/JSON。
2. ROS 2 工作区：src/build/install/log、colcon、source、package.xml、setup.py。
3. ROS 通信：节点、话题、消息、发布订阅、QoS；写两个节点互相发送数据并用 topic 命令检查。
4. 仿真与可视化：分清 Gazebo 和 RViz；理解 URDF/SDF、激光、相机及深度相机的数据来源。
5. 坐标：map、odom、base_link、camera optical frame、TF 变换及时间戳。
6. 建图与导航：分清 SLAM、定位和 Nav2；理解导航 Action 的反馈、完成、失败和取消。
7. 视觉：调用固定版本的预训练模型，读取类别、检测框和置信度，检查误检及漏检。
8. 三维定位：检查深度单位、RGB/深度对齐、相机内参、无效深度、时间同步和地图变换。
9. 去重与搜索：维护物品清单，理解匹配阈值、多次观测确认、房间边界与搜索终止条件。
10. 评估：计数误差、重复计数、漏检、定位误差、耗时及失败案例，所有结论对应实际结果文件。
