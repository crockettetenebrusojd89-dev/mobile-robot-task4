# 任务四语音演示与复现

从 `task4_ws` 根目录运行。录音和合成音频共用 Vosk 中文识别、关键词解析和 ROS 任务发布。合成音频通过文件输入，演示时可保持扬声器静音。

## 启动前

在当前项目环境安装 Vosk 0.3.45，把官方 `vosk-model-small-cn-0.22` 解到 `models/weights/`。本机已就绪。新环境可用以下命令准备。

```bash
.venv/bin/python -m pip install --target .venv/voice-python vosk==0.3.45
mkdir -p models/weights
voice_archive=$(mktemp /tmp/task4-vosk.XXXXXX.zip)
curl --fail --location --output "$voice_archive" \
  https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip
printf '%s  %s\n' \
  3af8b0e7e0f835ae9d414ce5df580237a3cfb08d586c9fbbb0f7ff29ad5b14ba \
  "$voice_archive" | sha256sum -c - &&
  python3 -m zipfile -e "$voice_archive" models/weights
bash build.sh
```

先按 [交接文档的定位与导航复现](交接文档.md#复现厨房入口导航) 启动 `task4_home`、设置 AMCL 初始位姿并激活 Nav2。确认激光、RGB-D、定位和导航服务就绪。项目参数中使用工作区相对路径，演示终端也保持在 `task4_ws`。

```bash
source sim_env.sh
ros2 launch task4_bringup task4_demo.launch.py
```

该入口启动 `object_locator` 和 `search_manager`。在另一个终端用相同的仿真环境触发任务。

## 用合成音频触发

```bash
source sim_env.sh
export PYTHONPATH="$PWD/.venv/voice-python:${PYTHONPATH:-}"
ros2 run task4_bringup voice_task \
  --wav results/m5_voice/2026-11-22_t5_4_piper/kitchen_full.wav --synthetic --dry-run
ros2 run task4_bringup voice_task \
  --wav results/m5_voice/2026-11-22_t5_4_piper/kitchen_full.wav --synthetic
```

第一条 `voice_task` 仅识别解析。确认输出 `room=kitchen` 和 `object_class=chair` 后运行第二条。程序在发任务前把音频及转写写入 `results/runs/<task_id>/voice.wav` 和 `voice.json`。运行完成后检查同目录的清单、状态和 `map_annotated.png`，用以下脚本核对。

```bash
run_dir=results/runs/t20261122-195902-voice-92a0c8e8
python3 scripts/verify_run.py "$run_dir"
python3 scripts/evaluate_run.py "$run_dir"
```

麦克风复现时，在允许说话的环境用 `ros2 run task4_bringup voice_task --record` 录 4 秒。若要先确认转写，可同时加 `--dry-run`。文件输入接受 16 kHz、单声道、16 位 PCM WAV，指定其他设备可用 `--device`。

## 重新合成样本

合成工具可单独安装到 `.venv/piper-tts`，与任务识别环境隔离。准备固定版本的 [Piper 普通话 Huayan 模型与配置](https://huggingface.co/rhasspy/piper-voices/tree/217ddc7/zh/zh_CN/huayan/medium)，将两文件放在 `models/weights/piper-huayan/`。

```bash
.venv/bin/python -m pip install --target .venv/piper-tts piper-tts==1.3.0
PYTHONPATH="$PWD/.venv/piper-tts" python3 scripts/synthesize_demo_wav.py \
  '去厨房数一下有几把椅子。' --out results/m5_voice/kitchen_prompt.wav
```
