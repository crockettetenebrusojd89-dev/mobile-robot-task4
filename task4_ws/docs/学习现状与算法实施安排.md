## 具体算法从什么时候开始

激光这一步已经进入最小数据算法：首个 ROS 2 数据处理节点已准备并由用户复现，目前逐行理解其筛选、最近值和坐标计算。无需先完成全部课次的理论阅读。

| 开始时机 | 学习内容与算法 | 亲自动手的成果 |
| --- | --- | --- |
| 当前继续阅读已有 scan_reader/scan_math | Node、订阅、回调、传感器 QoS；有限值与量程过滤、极坐标转平面坐标 | 只读示例已由用户复现；继续解释代码与坐标，独立修改/实现尚未验证 |
| 激光、基础 TF、仿真时间与运动检查通过后 | SLAM 的扫描匹配、占据栅格、位姿图与回环含义；先运行 SLAM Toolbox | 遥控机器人生成、保存并重新加载第一张地图，解释地图与轨迹为何变化 |
| 地图可用后 | AMCL 的运动预测、观测更新、重采样；A* 的 g/h/f 和路径搜索；Nav2 接口与局部控制 | 加载地图定位，测试指定点导航；写简化栅格 A* 练习帮助理解，项目导航使用经适配的现有组件 |
| 有可用的相机观测后，可与建图并行 | YOLO 推理、类别、置信度、检测误差 | 在实际仿真图像上验证模型，写检测调用和消息接口；先用预训练权重 |
| 目标能检测、相机几何对齐与时间关系验证后 | 深度稳健估计、内参反投影、观测时刻 TF 组合 | 自己写从像素/深度到地图坐标的处理，并从多个观察位置验证同一目标 |
| 单目标位置稳定后 | 按类别和距离关联、多次观测确认、一对一匹配、稳定编号 | 写物体记录与去重计数逻辑，测试重复看到、近邻目标及漏检 |
| 导航与计数模块各自通过后 | 任务状态机、观察点搜索、失败与取消、关键词解析 | 写房间搜索流程，接入现有语音识别，保存计数和地图标注 |

每个模块采用“解释最小原理 → 运行一次 → 分析输入输出 → 改代码或参数 → 用实际结果验证”的节奏。SLAM、AMCL、Nav2 和检测网络首版复用成熟实现；需要理解并适配它们的输入输出、参数和失败条件。项目内重点编写目标坐标处理、去重编号、搜索状态机、接口与结果保存。对基础算法的简化手写练习服务于理解，不替代完整成熟系统的验证。

NavFn 规划使用 A* 是项目方案，尚未配置运行；Humble 示例参数中 use_astar=false，实施时必须显式改为 true 并检查实际配置，不应把现有默认配置说成已经在跑 A*。
