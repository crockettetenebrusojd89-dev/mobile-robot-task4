## 本轮先理解这几行

主文件是 src/task4_bringup/task4_bringup/scan_reader.py。创建订阅的核心为：

```python
self.scan_subscription = self.create_subscription(
    LaserScan, "/scan", self.on_scan, qos_profile_sensor_data
)
```

| 代码 | 含义 |
| --- | --- |
| LaserScan | 期待收到的消息类型 |
| "/scan" | 订阅的话题 |
| self.on_scan | 每次收到消息后由 ROS 调用的处理函数，称为回调 |
| qos_profile_sensor_data | 使用传感器数据接收策略，包含 best effort；细节后续按需展开 |

回调参数 msg 是一整条扫描消息，msg.ranges 就是之前被 --no-arr 隐藏的距离数组。rclpy.spin(node) 让程序持续处理消息回调，直到停止。

这条订阅可读成一句话：接收 /scan 上的 LaserScan 消息，每次收到后调用 on_scan，采用传感器数据 QoS。on_scan 的参数 msg 是本次收到的那一整条消息；例如 msg.ranges 是本条消息的距离数组。注册订阅时传入的是处理函数，后续由 ROS 在消息到达时调用。

## 数据算法放在哪里

纯计算文件是 src/task4_bringup/task4_bringup/scan_math.py。先筛选有限、量程内的距离，再找最小值。保留该距离在原数组中的序号 i，从而得到它原来的测量方向：

```text
theta = angle_min + i × angle_increment
x = distance × cos(theta)
y = distance × sin(theta)
```

角度计算用弧度；输出额外换成度方便阅读。x、y 是本条扫描 frame 中的平面坐标。不能先删除无效值后重新编号，再用新编号算角度，否则方向会错位。

例如人为取某束 angle=π/2、distance=1 米，点坐标约为 (0,1) 米；这个算例不代表实际收到的回波。三角函数和逐行实现将在看过运行结果后讲解，不要求当前一次掌握整个文件。
