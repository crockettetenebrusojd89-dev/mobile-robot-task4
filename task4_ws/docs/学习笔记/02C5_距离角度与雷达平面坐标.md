## 1. 只有距离，不能确定点的位置

“距离雷达 2 米”只说明有多远。雷达前面 2 米、左边 2 米和右边 2 米都满足这个距离。

还需要方向角，才能确定本次测量对应的平面点。这种用距离 r 和方向角 θ 描述点的方式叫极坐标；用 x、y 描述同一点的方式叫平面直角坐标。

本轮只需阅读和手算，不要求新的仿真运行。

## 2. 先约定雷达自己的坐标轴

LaserScan 中的方向和点坐标属于 header.frame_id 指定的雷达坐标系。角度从 +X 轴开始，绕 +Z 轴计量；当 +Z 朝上时，从上方看正角为逆时针。

教学图把 +X 画成屏幕向上、+Y 画成屏幕向左：

```text
                   +X，0°
                      ↑
    +Y，+90°  ←   雷达原点   →  −Y，−90°
                      ↓
                   −X，±180°
```

这里的“前方”指雷达 +X 方向；“左、右”按面向雷达 +X 的方向区分。还不能仅凭这张图确认雷达轴与底盘轴实际对齐，安装关系需要 TF 验证。也不要把屏幕横向当成坐标 x：上图的 +X 特意朝屏幕上方。

你之前收到的 frame_id 是 turtlebot4/rplidar_link/rplidar。因此本课从该消息计算的点，也属于这个 frame，而不是 base_link、odom 或 map。

## 3. 原序号怎样对应方向角

LaserScan 给出起始角度 angle_min，以及相邻样本的角度间隔 angle_increment。原序号 i 对应的方向为：

```text
θ = angle_min + i × angle_increment
```

原序号从 0 开始。序号 0 对应起始角度，序号 1 在此基础上增加一个角度间隔，依次类推。

假设一组教学扫描从 −180° 开始，间隔 45°：

| 原序号 i | 方向角 |
| --- | --- |
| 0 | −180° |
| 1 | −135° |
| 2 | −90° |
| 3 | −45° |
| 4 | 0° |
| 5 | +45° |
| 6 | +90° |

这是便于手算的假设，不是当前雷达的真实角度间隔。实际消息的间隔约 0.00983284 弧度，即 0.563°，代码使用消息里的数值。

为什么筛选后仍保留原序号？例如原序号 5 对应 +45°，即使前面有无效数据被跳过，它仍对应 +45°。如果重新编号，套公式就会得到错误方向。

## 4. 距离和方向怎样变成 x、y

使用公式：

```text
x = r × cos(θ)
y = r × sin(θ)
```

r 是有效测量距离，单位米；θ 是方向角。x、y 是这个距离在两条坐标轴上的分量，单位同样为米。也可以把它理解为把一条斜线拆成沿 X 和 Y 的两段投影。

先看三个容易判断的方向：

| 距离 | 方向 | 平面坐标 (x, y)，米 | 含义 |
| --- | --- | --- | --- |
| 2 米 | 0° | (2, 0) | 沿雷达 +X 方向 2 米 |
| 2 米 | +90° | (0, 2) | 沿雷达 +Y 方向 2 米 |
| 2 米 | −90° | (0, −2) | 沿雷达 −Y 方向 2 米 |
| 2 米 | +45° | 约 (1.414, 1.414) | 位于 +X、+Y 之间 |

45° 时，两个分量不是各 2 米。由 (1.414, 1.414) 到原点的直线距离约为 2 米，符合原始测量。

## 5. Python 代码里的角度使用弧度

LaserScan 的角度字段单位是弧度，Python math.sin 和 math.cos 也接收弧度。

```text
180° = π 弧度
90° = π/2 弧度
角度数 × π/180 = 弧度数
```

因此不能直接把数字 90 传给 math.sin 来表达 90°。可用 math.radians(90) 把度转成弧度；用 math.degrees(angle) 把弧度转换成度以便显示。真实消息的角度已经是弧度，不要再重复转换。

下面把教学扫描的原序号 5、距离 2 米连起来：

```python
import math

angle_min = math.radians(-180)
angle_increment = math.radians(45)
index = 5
distance = 2.0

angle = angle_min + index * angle_increment
x = distance * math.cos(angle)
y = distance * math.sin(angle)

print(round(math.degrees(angle), 1))
print(round(x, 3), round(y, 3))
```

预期输出：

```text
45.0
1.414 1.414
```

这里的 * 表示乘法，round(value, 3) 用于把显示值四舍五入到小数点后 3 位，不改变物理单位。三角函数和浮点数计算会使某些理论上的 0 显示为很小的数，例如 1e-16；在此类方向算例中可按接近 0 理解。

## 6. 对照你之前的实际输出

你之前的扫描摘要显示：最近距离约 1 米、原序号 0、方向约 −180°、雷达平面坐标约 (−1, 0) 米。

因为原序号 0 对应 angle_min≈−π，故：

```text
x ≈ 1 × cos(−π) = −1 米
y ≈ 1 × sin(−π) = 0 米
```

这和终端输出相符。它说明该最近回波位于雷达 −X 一侧约 1 米；不由此认定它在机器人底盘后方，也不把 (−1, 0) 当成地图位置。雷达到底盘的安装 TF 尚未验证。
