# 任务四实施路线

2026-11-07 更新：具体技术栈、平台选择和日期安排以 [技术路线](技术路线.md) 为准；首步操作见 [仿真与传感器验收](第一步_仿真与传感器验收.md)。以下保留初始阶段概述。

先完成单目标搜寻与可靠的地图定位，再增加去重计数和标注。首版建议采用静态物品、预先保存的地图、预训练模型，以及每个房间的观察点序列。它们是工程方案，尚未作为已实现能力。

## 阶段检查点

| 阶段 | 交付物 | 进入下一阶段的条件 |
| --- | --- | --- |
| M0 工作区 | 资料、文档、包骨架、环境检查 | 基础构建与包入口验证通过 |
| M1 仿真与导航 | 已核实的模型、传感器、地图和房间配置 | 图像、深度、相机参数、激光、TF 可用；能导航到房间 |
| M2 单目标定位 | 检测结果及目标地图坐标 | 同一目标从多个观察位置测得位置基本一致，并记录误差 |
| M3 去重与计数 | 物品清单、稳定编号和更新规则 | 重复观察不会明显增加数量，相邻目标不被轻易合并 |
| M4 完整任务 | 语音、观察点搜索、汇总、地图标注保存 | 包含零目标、导航失败和传感器缺失的结果处理 |
| M5 评估与展示 | 数据、图片、演示视频、PPT、报告 | 所有结论对应实际实验记录 |

当前日期为 2026-11-07。距离 11 月 27 日展示约 20 天，建议前 4 天完成 M1，第 5—8 天完成 M2，第 9—12 天完成 M3，第 13—16 天完成 M4，最后几天用于 M5。此安排是目标节奏，不是工期保证。

## 建议分工

- A：仿真场景、传感器、建图、定位、导航与观察点执行。
- B：图像检测、深度处理、图像与深度对齐、时间同步、相机到地图坐标变换。
- C：语音任务、状态调度、物品关联与编号、结果标注和保存。
- 全组共同确定接口，完成集成测试和报告。人员姓名、实际贡献在工作日志中据实补充。

## 早期验证

最早验证同一物体在不同观察位置下的地图坐标一致性。距离关联阈值需结合定位误差和物体间距确定；不能用未经验证的固定距离当作可靠去重方案。

初期可从一个房间调试，但正式版本应保留任务要求中的房间命名与指定房间能力。搜索计划应记录观察位置、朝向和完成状态，识别范围应限制在目标房间。
