# 模型

保存机器人和传感器的项目级修改；第三方模型记录来源与版本。检测权重下载后放入 weights/ 并记录校验值，该目录不纳入 Git。

[task4_chair](task4_chair/model.sdf) 是项目自制的静态椅子，由椅背、坐面和四条腿组成。场景用同一个模型摆放五把椅子，每把椅子在世界中有独立的名字和位姿。模型来源、版本和文件校验值见 [manifest.json](manifest.json)。外观是否适合检测器由 T3.1 实测。

T3.1 的 YOLOv8n 对照实验使用 Ultralytics 正式发布的 `yolov8n.pt`。权重的发布地址、校验值、许可证和实测运行版本见模型清单。项目复现命令与检测结果见交接文档。 [模型清单](manifest.json) · [检测验收](../docs/交接文档.md#t31-椅子检测可行性)
