## 从这里开始

在本目录打开终端，依次执行：

```bash
source env.sh
python3 scripts/check_environment.py
bash build.sh
source env.sh
ros2 run task4_bringup workspace_info
```

最后一条命令只检查新建包是否能够被 ROS 2 发现，不启动仿真、不控制机器人。

`build.sh` 使用项目内的 colcon 入口，在 Linux/Python 3.10 中为构建进程选择兼容的子进程监视方式，解决当前受限执行环境中出现的等待；系统安装保持原样。

当前电脑为 Ubuntu 22.04、ROS 2 Humble。老师任务书采用 TurtleBot2，教程采用 TurtleBot3/Gazebo Classic。首步开发验证暂用本机已有 TurtleBot4 Lite/Fortress，最终课程型号要求尚待核实。请在新终端操作，以便辨认其他实验工作区的环境影响。
