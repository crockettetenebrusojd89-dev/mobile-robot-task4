# 地图

这里保存由项目建图得到的二维占据栅格图像和 YAML。任务四的正式地图待 T2.3 键盘遥控建图、T2.4 保存与重载。随后在 T2.5 用地图坐标命名客厅、厨房和卧室。

已收到的教师教程压缩包只有三个 PDF，里面没有附带可加载的地图文件。TurtleBot4 自带的 `maze`、`depot`、`warehouse` 地图属于示例资源，可用于熟悉地图加载。

`worlds/` 的 SDF 定义 Gazebo 里地面、墙和家具的位置。`maps/` 的地图来自机器人扫描，会保存哪些格子可通行、被占用或尚未观测。 [任务书要求](../docs/任务要求与验收.md) · [仿真场景](../worlds/README.md)
